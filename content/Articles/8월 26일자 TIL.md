## Bunnies

피보나치 수열 문제 풀기
Fibonacci Numbers

base case

fibonacci(0) = 0
fibonacci(1) = 1

fibonacci(n) = fibonacci(n-1) + fibonacci(n-2)
(단 n = 정수 and n>1)

Define a procedure, Fibonacci, that takes a natural number as its input, and outputs the value of that fibonacci number.
```python
def Fibonacci(n):
    if n == 0:
        return 0
    if n == 1 :
        return 1
    return fibonacci(n-1) + fibonacci(n-2)
```
