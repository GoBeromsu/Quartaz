quiz
Suppose we have b buckets and k keywords (k > b). which of these properties should
the hash function have?

해시 함수에 속성이 있어야 하는가?

output a unique number between 0 and k-1
0 output a number between 0 and b - 1 keyword
k > b 이니까 숫자가 b -1 keyword 까지 있어야한다.
0map approximately k/b keywords to buckt 0
대략적으로 버켓 안에 있는 수 만큼으로 키워드를 나누어서 저장 해야한다.
0map approximately k/b keywords to bucket b-1
이건 이해가 잘안되서 수요일에 물어봐야겠다. 왜 b-1까지 대입하는건 괜찮은 거지?
