## 풀이

```python
def solution(nums):
    answer=0
    s = list(set(nums))
    size = len(nums)/2 if len(nums)%2==0 else int(len(nums)/2)+1
    if size>len(s):
        answer = len(s)
    else:
        answer = size
    return answer
```
