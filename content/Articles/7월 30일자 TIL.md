Dictionary = key + value

example = 사람 : 범수
{Key1:Value1, Key2:Value2, Key3:Value3 ...}

key 와 value 의 형태로 이루어져 있고, 쌍끼리는 ,로 구분한다.

Dictionary의 value 값에는 list도 넣을 수 있다.

1. dictionary 쌍 추가하기

```python
a = { 1 : 'a'}
```
a[2] = 'b'

dic[key] = value 형태로 dictionary 쌍을 추가할 수 있다. 반대로 del dic[key] = value는 dictionary 쌍을 삭제하는 방법이다.

dictionary 사용법은 말 그대로 사전처럼 사용하는 것이다. dic 안에 분류 대상을 정리해 놓고, 필요한 파트만 꺼내서 사용하는 것이다.

Ex. a = { 1 : 'a', 2 : 'b' }
     a[1] = 'a' 형태로 사용하는데,
     key 와 value 값을 뒤집어서 사용해도 괜찮다.

Modifying our Search Engine

which of the procedures in our search engine do we need to change to replace of list index with a dictionary index?
검색 엔진 내의 어떤 procedure를 list index에서 dictionary index로 바꿔야 하는가?

```python
def crawl_web(seed):
    tocrawl = [seed]
    crawled = []
    index = []
    while tocrawl:
        page = tocrawl.pop()
        if page not in crawled:
            content = get_page(page)
            add_page_to_index(index, page, content)
            union(tocrawl, get_all_links(content))
            crawled.append(page)
    return index

def add_to_index(index, keyword, url):
    for entry in index:
        if entry[0] == keyword: entry[1].append(url)
            return
    # not found, add new keyword to index
    index.append([keyword, [url]])

def lookup(index, keyword):
    for entry in index:
        if entry[0] == keyword:
            return entry[1]
    return None
```

procedure를 실행할 때 dictionary 를 사용하면 리스트를 따라 하나하나 대응하는 것보다 속도가 빠르다.
