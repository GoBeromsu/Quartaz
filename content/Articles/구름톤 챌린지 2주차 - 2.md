## 폭탄 구현하기 2

![구름톤 챌린지 폭탄 구현하기 (2) 문제 설명](/_attachments/tistory-489-01.png)

```python
N,K = map(int,input().split())

mp = [list(input().split()) for _ in range(N)]
m = [[0 for _ in range(N)] for _ in range(N)]

def check(y,x):
	y-=1
	x-=1
	global mp,m
	if y <0 or y==N or x<0 or x==N:
		return
	if mp[y][x]=="#":
		return
	elif mp[y][x]=="@":
		m[y][x]+=2
	else:
		m[y][x]+=1

for _ in range(K):
	y,x = map(int,input().split())
	check(y,x)
	check(y+1,x)
	check(y-1,x)
	check(y,x-1)
	check(y,x+1)
result= 0
for i in m:
	result = max(i) if max(i) >result else result
print(result)
```

완전 탐색으로 맵을 순회하고, 값을 반환하는 형태로 구현하였다
