1. SQL인젝션이란?

1.1 SQL인젝션의 정의

응용 프로그램 보안 상의 허점을 의도적으로 이용해, 악의적인 SQL문을 실행되게 함으로써 데이터베이스를 비정상적으로 조작하는 코드 인젝션 공격 방법이다. SQL 삽입은 SQL 문에 포함된 문자열 리터럴 이스케이프 문자에 대해 사용자 입력이 잘못 필터링되거나, 사용자 입력이 강력하게 입력되어 예기치 않게 실행되는 경우처럼 응용 프로그램의 소프트웨어 보안 취약점을 악용한다. SQL 인젝션은 주로 웹 사이트의 공격 경로로 알려져 있지만, 모든 유형의 SQL 데이터베이스를 공격하는 데 쓰일 수 있다.

* SQL문이란?
관계형 데이터베이스 관리 시스템(RDBMS)의 데이터를 관리하기 위해 설계된 특수 목적의 프로그래밍 언어

1.2 SQL인젝션 원리

DataBase와 애플리케이션 간에 질의하는 과정, 즉 데이터를 주고받는 상황에서 공격자가 임의의 SQL문을 삽입해 SQL 쿼리문을 다루게 된다.

1. 공격하고자 하는 웹페이지의 쿼리 구조를 파악한다.
2. 파악한 쿼리 구조의 취약점을 분석(DataBase 에러가 많을수록 유리)
3. 임의로 구조에 합당하는 SQL문을 삽입한다.

공격순서 : 취약한 URL 파라미터 – DB - 테이블 - 컬럼

2. SQL 인젝션 종류

2.1 인증 우회

로그인을 요구하는 웹페이지에서 Id/Pd 대신 쿼리문을 입력해 로그인을 우회하는 것이다. 쿼리 결과를 무조건 참(TRUE)으로 나오게 해서 인증을 무력화시키는 기법이다. 해커 입장에서는 최종적으로 where문만 참으로 만들어 주면 되는 것이다.

● where 조건이 참이 되면 DB의 처리가 참이 된 것을 뜻하기 때문에 로그인이 성공하는 것이다.

where문이란?

WHERE 절은 데이터를 추출하는 선택 조건식을 지정한다. 단일 식을 이용하는 것 외에도, 여러 조건을 조회하는 경우도 많다. 또한 테이블 간에 결합할 때 그 결합 관계를 지정한다.

2.2 데이터 노출

타겟 시스템의 주요 데이터 절취를 목적으로 하는 방식이며 Error based, Union based, Blind based, Time based 방식이 있다. 공격 방식을 결정하기에 앞서 공통적으로 반드시 필요한 것은 포인트를 찾는 일이다. 웹사이트는 사용자와 상호작용을 위해 사용자의 입력 혹은 사용자의 특정 행위에 따라 URL상의 파라미터로 특정 값이 전달되어 뒷단에 있는 DataBase에 질의를 던지고, 그에 따른 적절한 결과를 사용자에게 제공한다.

3. 실습

SQLMAP이라는 해킹 툴을 이용해 간단한 실습을 해 보려고 한다.
1. 구글에서 SQL Injection에 취약한 웹사이트를 찾는다.
2. 발견한 웹사이트의 컬럼과 테이블을 파악한다.

여기서 멈출 예정이다. 컬럼과 테이블까지 파악했으니 사실상 원한다면 SQL 인젝션 공격을 할 수 있다. 하지만 더 나가면 범죄이므로 사이트 운영자에게 메일로 알려 주자.

1. SQLMAP을 깔아야 한다. (python2.6, 2.7이 window에 깔려 있어야 한다.)
