## virtual box에 ubuntu설치하기

VM(가상머신) : Oracle VM Virutal Box.

ISO : Ubuntu16.04(호환성도 그렇고 유효기간이 제일 긴걸로 알아서 설치하기로했다.)

1. VM을 실행 한 후 새로 만들기 클릭
2. 이름이랑 운영체제를 고른다(이름에 os이름 치니까 알아서 종류랑 버전 맞춰지더라)
3. 설치할 iso파일을 골라준다.(나같은 경우 ubunto)
4. 그 후 메모리 할당, 하드디스크 용량 정하기 등을 하는데 기본설정대로 진행하면 된다.

## Django 설치 및 설정

Ptyhon 환경에서 봇을 만들 것이므로 Linux에 Python verision을 확인한다.

```bash
~$ python3 --version

python 3.5.1+
```
내 컴퓨터에는 ptyhon 3.5.1이 깔려 있음을 알 수 있다.

이제 Django를 설치해보자

```bash

~$ pip3 install --upgrade pip
~$ pip3 install django
```

이렇게 입력 하면 설치 완료!

but 나 같은 경우에는 안됬다.

이럴 땐!
1. apt install python3-pip
2. root권한을 얻고 다시 해보는 거다
```bash
~$ sudo -i
~# apt install python3-pip
~# pip3 install django
```
