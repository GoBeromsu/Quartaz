**Me.md는 이름과 좋아하는 것부터 적어도 된다**

```text
## Summary Statement
이름 · 나이 · 학교 · 학과 · 지금 관심 있는 것 한 줄
## First Principles
내가 중요하게 여기는 것 한두 가지
## How I Think
막힐 때 어떻게 푸는지 (먼저 검색 / 먼저 물어봄 / 먼저 그림)
## Working Preferences
이런 사람이 좋다 · 이런 사람이 싫다 · AI 답변은 짧게/길게
## 나에게 영향을 주는 사람
이름만 한 줄에 하나
```

왜 먼저 쓰나

Agent는 파일을 읽고 일합니다. 나를 적은 파일이 있어야 내 기준으로 판단합니다.

어제 Gemini 세 질문으로 만든 초안이 있으면 그것을 붙입니다.

완벽한 문장이 아니어도 됩니다. 사실 몇 줄이면 오늘 실습에 충분합니다.

다섯 ## 제목은 그대로 두고, 각 제목 아래 > 역할: 줄은 지워도 됩니다.

5분 · Me.md에 이름 · 학과 · 좋아하는 것 · 좋은 사람 · 싫은 사람을 적습니다.

M06 · 템플릿 · 공개 템플릿의 실제 파일

**템플릿은 속성 이름을 고정하는 파일이다**

```text
---
type: note
created_by: user
authorship: user
date_created: <% tp.date.now("YYYY-MM-DD") %>
date_modified: <% tp.date.now("YYYY-MM-DD") %>
tags: []
aliases: []
---
```

읽는 법

type · 이 노트가 무엇인지. Base가 가장 먼저 거르는 속성입니다.

created\_by · authorship · 사람이 쓴 노트 표시.

&lt;% tp.date.now() %> · Templater가 오늘 날짜로 바꿔 넣는 자리.

tags · aliases · 검색과 링크에 쓰는 이름.

M06 · Bases란 무엇인가 · 여러분 vault의 실제 파일 · 90. Settings/05 Bases/Video.base

**Base는 속성이 같은 노트를 자동으로 모아 보여 주는 화면이다**

파일 하나에 filters(무엇을 모을지)와 views(어떻게 볼지)만 적습니다. 목록을 손으로 고치지 않습니다.

```text
filters:
  and:
    - type == "video"
    - "!file.inFolder("90. Settings/02 Templates")"
views:
  - type: cards
    name: By author
    groupBy:
      property: author
      direction: ASC
    sort:
      - property: date_published
        direction: DESC
    image: note.image
    cardSize: 220
```

읽는 법

filters · 어떤 노트를 모을지. type이 video이고 템플릿 폴더 밖인 노트.

views · 어떻게 볼지. 카드(cards) 하나, 표(table) 하나.

groupBy · author로 묶기 · sort · 발행일 내림차순.

image · 카드에 쓸 이미지 속성.

공개 템플릿 90. Settings/05 Bases/Video.base 발췌 · 여러분 vault에 이미 있습니다

Base는 YAML 한 장입니다. Agent가 만들기 쉽고, 사람이 읽고 고치기도 쉽습니다.

90. Settings/02 Templates/manual/video.template.md 를 읽어 줘.

이 프롬프트의 구조

**Obsidian에서 템플릿으로 노트 두 개를 만든다**

01 Antigravity가 보고한 경로에 movie.template.md가 생겼는지 파일 탐색기에서 봅니다.

02 Obsidian에서 새 노트 → 명령어 팔레트 → Templater: Open insert template modal → movie 선택.

03 속성 창에 type: movie와 title · director · year · genre · poster\_url이 보이는지, date\_created에 오늘 날짜가 들어갔는지 봅니다.

04 최근 본 영화 두 편으로 노트 두 개를 만들고 속성을 채웁니다. 포스터 주소는 검색 결과의 이미지 주소를 복사합니다. 파일은 80. References/ 아래 새 폴더 03 Movie/에 둡니다.

어긋나면 Agent에게 무엇이 다른지 한 줄로 알려 주고 다시 만들게 합니다. 파일을 손으로 고치기보다 템플릿을 고칩니다.

구성 · 프롬프트 2 · 내 자료 종류의 Base · 11:15–11:30

**Video.base를 읽고 같은 구조로 Movies.base를 만들게 한다**

```text
90. Settings/05 Bases/Video.base 를 읽어 줘.

같은 구조로 90. Settings/05 Bases/Movies.base 를 만들어 줘.
filters 는 type == "movie" 이고 템플릿 폴더 밖인 노트.
views 는 cards 하나. genre 로 묶고(groupBy),
year 내림차순으로 정렬(sort)해 줘.
카드 이미지는 poster_url 속성을 써 줘.

파일 하나만 만들고, 만든 파일의 경로와 내용을 보여 줘.
```

앞 장의 실제 파일과 같은 구조

filters · 프롬프트 1이 정한 type

views · Video.base와 같은 cards · groupBy · sort · image

속성 이름 · 프롬프트 1과 같은 이름을 씁니다. 대소문자까지 같아야 합니다.

이미지가 없는 종류면 table로 바꾸고 열(order)을 적습니다.

템플릿과 Base는 같은 속성 이름으로 이어집니다. 그래서 순서가 템플릿 → Base입니다.
