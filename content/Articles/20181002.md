## Whois server

* whois는 도메인 확인 및 도메인과 관련된 사람과 인터넷의 자원을 찾아보기 위한 프로토콜로 만들어졌다.
* 초기 whois는 사용자 이름 및 관련 정보만으로 관련 도메인을 모두 검색할 수 있었다.

### DNS

* 쉽게 말해 여러 별명들을 하나로 통일시켜 주는 것이라 생각하면 된다.
* IP주소를 인간이 이해하기 쉬운 명칭으로 바꾼 것이다.

host 파일 기본 구조
* IP Address : domain name, nick name
![host](https://user-images.githubusercontent.com/37897508/47013904-adb45e00-d183-11e8-9ca7-3c93cf366f78.PNG)

DNS 객체 순위

www.naver.com에서 .(root)은 객체 순위에 따라 기록되는 것이다.

1. 국가 (com, net, org, kr, jp)
2. 조직의 특성 (co, ac)
3. 특정 서버의 이름 (www, ftp)

www.naver.com과 같이 완성된 이름을 FQDN(Fully Qualified Domain Name)이라 한다.

### hosts 파일을 이용해 이름 해석

1. 특정 주소에 대한 ping을 실행해 본다.
2. C:\Windows\System32\drivers\etc의 host 파일에 ip를 입력하고 임의의 이름으로 바꾼다.
* 잘못된 이름을 입력할 경우 설정한 이름으로 접속이 불가능하다.
