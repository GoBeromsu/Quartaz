## 문제
M이상 N이하의 소수를 모두 출력하는 프로그램을 작성하시오.
## 풀이

* N이하의 소수들을 모두 구한 후 M과 N 사이의 소수를 출력한다

## CODE

```python
import sys
M,N = map(int, sys.stdin.readline().split())
arr = [False,False] + [True] * (N-1)
for i in range(2,N+1):
    for j in range(2*i,N+1,i):
        arr[j] = False
for i in range(M,N+1):
    if arr[i] == True:
        print(i)
```
