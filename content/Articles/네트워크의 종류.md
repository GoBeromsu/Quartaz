## 데이터 전송 방식에 따른 네트워크 분류

1. 회선 교환망

통신 전에 물리적 연결로 전용 통신 선로를 설정하여 통신이 끝날 때까지 연결을 독점적으로 사용하는 방식이다.
Ex. 전화기(거미줄 - 폐쇄 회로)

* 일단 연결이 시작되면ㅍ 중간에 제 3자와 공유 불가능
* 전송 지연이 거의 없다.

2. 패킷 교환망

정보를 패킷으로 쪼개 팻키 교환기로 보낸다.
* 패킷 = (발신지 + 수신지)의 주소를 담아 패킷 교환 망에 보냄
* 통신 경로가 통신시에 확정되지 않는다.(위험하다?)
* 패킷 교환망 = 라우터 : 패킷을 전송할 때 라우터가 아는 가장 빠른 길로 패킷을 전송한다.

3. 셀 교환망

망 내 프로토콜을 간략화하여 데이터를 셀(패킷 단위)로 전송한다.
* 흐름 제어와 오류 제어는 단말 간에서 처리하게 함으로써 고속성을 실현할 수 있다.
* 고속 네트워크 전송에 효율적이다.

### 위상에 따른 네트워크 분류

1. 버스형

통신 회선 하나를 모든 노드가 공유한다.
* 한 노드에서 전송한 메세지가 모든 노드에 전달(broadcasting)
* 노드가 증가하면 노드간 통신 시 충돌로 인해 속도가 떨어진다.

2. 스타형

중앙 제어 노드가 통신의 모든 제어를 관리한다.
* 노드 간의 데이터가 다른 노드에 전달되지 않는다.
* 중앙 노드가 네트워크 성능을 좌우한다.
but 중앙 제어 노드가 작동을 못하면 네트워크가 정지 된다.

3. 링형

링형 네트워크에서는 네트워크의 한 노드에라도 이상이 생기면 통신망이 정지
토큰을 받아야 데이터를 전송할 수 있어 데이터 전송에 지연시간이 발생한다.

4. 허브/트리형

버스형의 변형으로 작은 버스형 네트워크 여러 개를 게층적으로 연결한 형태

### 규모에 따른 네트워크 분류

1. Lan

일반적으로 300m 이하의 통신 회선으로 연결된 pc메인 프레임과 워크스테이션의 집합을 말한다.
한 기관의 건물에 설치된 컴퓨터 장비를 가장 효과적으로 사용할 있도록 연결된 고속 통신망

2. Man

Lan을 고속의  backbone으로 묶은 형태로 Lan 수준의 높은 데이터 전송률을 제공한다.
보통 도시 또는 크 캠퍼스를 네트워크 하나로 서로 연결하는데 적용한다.

3. Wan

지리적으로 흩어진 통신망을 의미한다.
넓은 지역을 연결하는 네트워크로 지방과 지방 국가와 국가 댉과 대륙처럼 지리적으로 완전하게 떨어진 장거리 지역사이를 연결한다.

## 프로토콜에 대한 이해

### 프로토콜의 개념

구문 : 데이터의 형식이나 신호로, 부호화 방법 등을 정의한다.
의미 : 오류 제어, 동기 제어, 흐름 제어 같은 각종 제어 절차에 관한 제어 정보를 정의 한다.
순서 : 송/수신자 간 혹은 양단의 통신 시스템과 망 사이의 통신 속도나 순서 등을 정의한다.

### 주소 설정

서로 다른 시스템의 두 개체가 점대점 통신이 아닌 통신을 하는 경우에 필요하다

* 프로토콜에는 각 전송 곛으에 맞는 주소를 지정하는 기능이 있다.
But 변조된 주소 값을 지닌 패킷을 보내면 네트워크나 시스템에 혼란을 줄 수 있다.

### 순서 제어

프로토콜 데이터 단위 : 데이터가 전송 될 때 일정 크기의 데이터 블록을 프로토콜 데이터 단위이다

순서 제어는 프로토콜 데이터 단위가 전송 될때 보내지는 순서를 명시하는 기능으로 연결 지향형에만 사용한다.

순서를 정하는 이유 : 전달, 흐름 제어, 오류제어 등을 위해서다.

순서가 정해진 각 PDU를 상대 개체에 보내면 수신측에서 순서에 맞게 데이터를 재구성한다.
* 이때 잘 못된 PDU는 재전송을 요구한다.

### 데이터 대열의 단편화 및 재조합

크기에 상관 없이 같은 프로토콜로 데이터를 전송 하기 때문에 큰 파일의 경우 효율성을 위해 쪼개고, 이를 전송 받는 시스템에서는 응용프로그램에 사용하기 위해 재조합 해야한다.

* 해커들의 경우 재조합 할 수 없는데 이터를 공격대상에게 보내 혼란에 빠트리기도 한다.

### 캡슐화

PDU = SDU(Service Data) + PCI(Protocol Control Information)

SDU = 전송하려는 데이터
PCI = 제어 정보 = 송신자와 수싡의 주소 검출 코드, 프로토콜 제어 정보 등이 있다.

데이터에 PCI를 덧 붙이는 것을 캡슐화라 한다.

### 연결 제어

연결 지향형 데이터 전송
= 두 시스템이 서로 데이터를 교환할 때 연결을 설정하는 경우
= 설정, 데이터 전송, 연결 해제라는 3단계로 구성된다.
Ex. Tcp를 이용한 연결(연결 제어 패킷을 이용해 네트워크 연결을 임의로 끊거나 해당 세션을 뺐을수 있다.)

비연결 지향형 데이터 전송
= 두 시스템이 서로 데이터를 교환 할 때 연결을 설정하지 않는 경우
Ex. UDP를 이용한 연결, 흔히 이렇게 전송 되는 데이터를 데이터 그램(datagram)이라한다.

### 흐름 제어

송신측 개체로부터 오는 데이터의 양이나 속도를 조절하는 기능이다.
= 송신측과 수신측의 속도 차이 등으로 인한 정보 유실을 방지한다.

1. 정지 대기 흐름 제어 기법
보낸 패킷에 대한 응답이 와야 다음 패킷을 보내는 방식

2. 슬라이딩 윈도우 기법
가용데이터 분량의 패킷을 한꺼번에 보낸다.(정지 대기 흐름 제어 기법보다 효율적)

### 오류제어

두 개체 간 데이터 교환에서 SDU 또는 PCI가 잘못되었을 경우, 이를 발견하는 기법

* 패리트 비트
정보 전달 과정에서 오류 검사를 위해 추가된 비트
* 순환 잉여도 검사
오류가 한꺼번에 많이 발생하는 비트들 즉 집단 오류를 해결하기 위한 오류제어 방식

### 동기화

두개체 간 데이터 전송을 할 때 각 각 특정 타이머 값이나 윈도우 크기등을 기억한다.
이렇게 잘 정의 된 두 개체가 동시에 잘 정의 된 인자 값을 공유하는 것을 동기화라한다.

### 다중화

통신 선로 하나에서 여러 시스템이 동시에 통신할 수 있는 기법

### 전송 서비스

우선 순위 결정, 서비스 등급과 보안 요구 등을 제어하는 서비스이다.
