## 문제 풀이

### 3일차 문제

![구름톤 챌린지 3일차 문제 설명](/_attachments/tistory-483-01.png)

```python
n = int(input())
result = 0
operations = {'+': lambda x, m: x + m, '/': lambda x, m: x // m, '-': lambda x, m: x - m, '*': lambda x, m: x * m}

for _ in range(n):
    x, v, m = input().split()
    result += operations[v](int(x), int(m))

print(result)
```

### 4일차 문제

![구름톤 챌린지 4일차 문제 설명](/_attachments/tistory-483-02.png)

```python
n  = int(input())
number = list(map(int,input().split()))

m = max(number)
check = True
z = False

count=0

if m == number[0]:
	count += 1

# 나머지 숫자를 확인하면서 패턴을 검사
for i in range(1, n):
		if m == number[i]:
				count += 1
				if count > 1 and number[i - 1] != m:
						z = True
				continue
		elif (count == 0 and number[i - 1] <= number[i]) or (count > 0 and number[i - 1] >= number[i]):
				continue
		else:
				z = True
print(0 if z else sum(number))
```

## 5일차

![구름톤 챌린지 5일차 문제 설명](/_attachments/tistory-483-03.png)  
![5일차 문제의 입력 조건: 정수의 수 N, 위치 K, 정수 a1부터 aN](/_attachments/tistory-483-04.png)

```python
n, k = map(int, input().split())
numbers = list(map(int, input().split()))

# 각 숫자의 1의 개수를 저장하는 리스트 생성
count_ones = [(num, bin(num).count('1')) for num in numbers]

# 먼저 1의 개수로 내림차순 정렬, 그 다음 10진수로 내림차순 정렬
sorted_numbers = sorted(count_ones, key=lambda x: (x[1], x[0]), reverse=True)

# k번째 수 출력
print(sorted_numbers[k-1][0])
```

입력 받은 수에서 1의 개수를 카운트 한 후, 1의 개수, 숫자의 크기 순으로 정렬하여 제출하면 된다
