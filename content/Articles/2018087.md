## Divide and Be Conquered
(나누고 다뤄져 보자 뭔소리여?)

이 강의는 피보나치 수열의 표준 수학적 정의 이다.
토끼로 예를 들어서 푼 기존의 문제랑은 조금 다르다.

```python
def fibonacci(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fibonacci(n-1) + fibonacci(n-2)
```

```python
print fibonacci(0)
```

0

```python
print fibonacci(1)
```

1

```python
print fibonacci(2)
```

1

## Faster Fibonacci

Define a faster fibonacci procedure that will endble us to  compute fibonacci(36)

fibonacci 수열의 규칙을 찾았으면 위의 procedure을 더 간단하게바꿔보자

일단 while문으로 반복해서 피보나치 수열 값을 생성하는게 맞는거 같음

while

* keep track of fibonacci(n-1) and fibonacci(n-2)

a = 0

```python
def fibonacci(n)
    if n = 0 :
        return 0
    else :
        while a = n :
            a = a + 1
```
