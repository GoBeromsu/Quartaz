## Divide and Be Conquered
(나누고 다뤄져 보자? 뭔 소리여?)

이 강의는 피보나치 수열의 표준 수학적 정의를 다룬다. 토끼로 예를 들어서 푼 기존의 문제랑은 조금 다르다.

```python
def fibonacci(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fibonacci(n-1) + fibonacci(n-2)
```

```python
print fibonacci(0)
```

0

```python
print fibonacci(1)
```

1

```python
print fibonacci(2)
```

1

## counting  Calls

How many times will we need to evaluate fibo(30) in evaluating fibo(36?)

일단 패턴을 찾아야 하는데,

fibonacci(36-(n-1)) = fibo(36 - n + 1) and fibo(36-n-1)

answer is 13

fibo(36)을 꼭대기에 두고 피라미드 형식으로 그려 내려가면 규칙을 확인할 수 있다. 그림판이 없으니 수요일에 모이면 그때 직접 설명하는 게 나을 것 같다.

## Faster Fibonacci

Define a faster fibonacci procedure that will enable us to compute fibonacci(36)

fibonacci 수열의 규칙을 찾았으면 위의 procedure를 더 간단하게 바꿔 보자. 일단 while문으로 반복해서 피보나치 수열 값을 생성하는 게 맞는 것 같다.

while

* keep track of fibonacci(n-1) and fibonacci(n-2)

a = 0

```python
def fibonacci(n)
    if n = 0 :
        return 0
    else :
        while a = n :
            a = a + 1
```
