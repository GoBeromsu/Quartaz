* HTML Tag

  ```html
   <body>
    <table border="1">
      <thead>
        <th>country</th>
        <th>color</th>
      </thead>
      <tr>
        <td>USA</td>
        <td>Red</td>
      </tr>
      <tr>
        <td>미국</td>
      </tr>
    </table>
   </body>

  ```
    * table tag
        * table> /table>
            * border = "n" n =  1 ~ 50 (굵기)

        * table head
            * thead> /thead>

            * table header cell
            * th> 제목 느낌?   /th>

        * table row
            * tr> header cell component /tr>

            *  table cell
                * td>       /td>

        table row가 순차적으로 table head에 속한다. (층별로)
