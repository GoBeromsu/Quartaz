## 보상

- 시크릿 세미나 : 인프랩 CTO 이동욱의 커리어여정과 취업과 성장에 대한 고민
- 스페셜 굿즈 : 티셔츠와 스티커

블록 개수 5,10,18에 따라서 다르다

- 5 개 : 알고리즘 {먼데이} 챌린지 1 해설 강좌
- 10 개 : 구름톤 챌린지가 끝나고 해설 강좌 제공
- 18 개 : 오프라인 팀 챌린지 참여 티켓

### 구름 채용 우대

- 오프라인 팀 챌린지까지 완주한 사람들에게는 구름 채용 우대 혜택
- 우수 참여자는 빠른 채용 프로세스를 제안할거다

### 챌린지까지

- 일주일에 2번 이상 블로그에 구름 톤 챌린지 학습 일기를 남기고, 컨테이너 학습 링크와 함께 인증
- 매주 네이버 포인트 5000 원 부여
- 4주차까지 꾸준히 작성하면 2만원 부여

## 문제

### 1일차 문제

![구름톤 챌린지 1RM 문제 설명](/_attachments/tistory-472-01.png)

```python
W,R = map(int,input().split())
result = W * (1 + R/30)
print(int(result))
```

첫날이라 그런지 간단한 문제가 나와서 곰방 풀었다

### 2일차 문제

![구름톤 챌린지 프로젝트 매니징 문제 설명](/_attachments/tistory-472-02.png)

```python
n = int(input())
h,m = map(int,input().split())

for i in range(n):
		m+=int(input())

h =   0 if (h+m//60)%24==0 else (h+m//60)%24
m = m%60

print(h,m)
```

![프로젝트 매니징 문제의 입출력 예시](/_attachments/tistory-472-03.png)  
현재 시각과 할 일들을 처리하는데 걸리는 시간을 차례차례 더해서, 00시만 조심해서 처리하면 된다  
24시계로 움직이기 때문에 24시 단위로 시간을 처리하였다
