## while문의 형식에 관하여

```c

int main(void)
{
    int num=0;
    while(num<3)
    {
        printf("hello world! %d \n", num);
        num++;
    }
}

```

while(조건문) 형식으로 반복문을 진행하고, {} 안에는 반복해야 할 문장을 넣는다.

## for문의 형식에 관하여

```c

int main(void)
{
    int num=0;
    for(num=0l num<3; num++)
        printf("Hi~");
}
```
for(초기식; 조건식; 증감식;) 형식으로 진행된다.
* 반복 영역이 한 줄이면 중괄호도 가능하다.
