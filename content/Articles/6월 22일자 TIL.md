모듈러스 연산자(%)

숫자%(modulus) = <Remainder>

숫자를 모듈러스로 나누고 나머지 값을 출력하라

hash string이란 함수에 변수 값은 keyword와 bucket으로 설정

```python
def hash string(keyword,buckets):
      h = 0
      for c in keyword:
      h = (h+ ord(c))%buckets
```

input = keyword
근데 처음에 h = (h+ord(c)%buckets)에서 h를 빼고 실행했을 때 오류는 안떳는데
string에 두글자를 넣으니까 답이 다르게 나온다.
애초에 프로그램은 순차적으로 실행되니까 (h+ord(c)%buckets) 실행 할때
위에서 h = 0 으로 초기화 했으니까 값의 차이가 없어야 되는거 아닌가?

A : for문을 사용하여 복수의 글자가 입력 될 경우 각각의 글자 하나 씩 구해서 h에 저장 한 후 한번에 bucket을
     돌려 모듈러스 함수에 집어넣습니다. 즉 초기화는 쓰레기값 처리를 위해 당연히 해야 하는 것이고
     h는 복수의 글자가 입력될 경우 글자 하나하나 값이 초기화 되지 않도록 하기위해서 존재하는 것이죠
