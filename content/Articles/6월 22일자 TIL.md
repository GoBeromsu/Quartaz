모듈러스 연산자(%)

숫자%(modulus) = <Remainder>

숫자를 모듈러스로 나누고 나머지 값을 출력하라는 뜻이다.

hash string이라는 함수에서 변수 값은 keyword와 bucket으로 설정했다.

```python
def hash string(keyword,buckets):
      h = 0
      for c in keyword:
      h = (h+ ord(c))%buckets
```

input = keyword
그런데 처음에 h = (h+ord(c)%buckets)에서 h를 빼고 실행했을 때, 오류는 안 떴는데 string에 두 글자를 넣으니까 답이 다르게 나왔다. 애초에 프로그램은 순차적으로 실행되니까, (h+ord(c)%buckets)를 실행할 때 위에서 h = 0 으로 초기화했으니 값의 차이가 없어야 되는 거 아닌가?

A : for문을 사용해서 복수의 글자가 입력될 경우 글자 하나씩 값을 구해 h에 저장한 뒤, 한 번에 bucket을 돌려 모듈러스 함수에 집어넣는다. 즉 초기화는 쓰레기값 처리를 위해 당연히 해야 하는 것이고, h는 복수의 글자가 입력될 경우 글자 하나하나의 값이 초기화되지 않도록 하기 위해서 존재하는 것이다.
