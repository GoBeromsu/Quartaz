## Recursive Definitions(반복되는 정의)

Two parts :
1. Base case - a starting point
Not defind in terms of itself
smallest input - already know the answer
2. Recursive case
Defined in terms of "smaller" version of itself

## Recursive Factorial

Define a procedure, factorial, that takes a natural number as its input, and outputs, the number of ways to arrange the input number of items.

```python
define factorial(n):
     if n== 0:
        return 1
     else:
         return n * factorial(n-1)
```

if~ return1 = base case

else~ factorial(n-1) = recursive structure
