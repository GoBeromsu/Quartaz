## QUIZ Adding Keywords

```python
hashtable_add(htable, key, value)이 수행해야될 역할은 올바른 bucket을 찾는 것이다.

def hash table_add(hatble, key,value):
    bucket = hashtable_get_bucket(htable, key).append([key, value])
```

hash table_add의 역할 : 해쉬테이블 키(올바른 버킷 내의) 정확한 value와 함께
새로운 hash table을 만들자.

.append를 def(a,b).append(c,d)형태로 쓸 수 있을줄은 몰랐는데 생각해보니 원래 쓰던 형태라 똑같은데 괜한 오해를 했다.

lookup(htable,word)의 역할
1. 버킷 찾기 = hashtable_get_bucket(htable, key)
2. 올바른 entry에서 key 값이 일치하는지 안하는지 찾아본다!

```python
def hashtable_lookup(htable, key):
    bucket = hashtable_get_bucket(htable, key)
    for entry in bucket:
        if entry[0] == key:
           return entry[1]
    return None
```
