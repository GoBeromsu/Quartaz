시작하기 앞서 GIT Hub란 무엇인가?

솔직히 대학교 들어오기 전까진 GIT hub가 무엇인인지 몰랐는데 정보보호 119 활동을 하면서 알게되었다.
git이 다루기 어렵다 생각하는데 아마 이유는 명령어를 쳐야되서 그런거 같다. 처음이라 복잡하기도 하고

What is Github

분산 버전 관리 툴인 GIT을 사용하는 프로젝트 지원 웹 호스팅 서비스이다.

한 번에 이해되는 정의는 아닙니다. 그러면 GIT이란 무엇일까요??

GIT이란 버전 관리 툴입니다. 즉 VCS(Version Control System)인거죠
마인크래프트를 예시로 들면 버전이 점점 상승할 수록 성능이 좋아지고 이전 버전과 차이점이 생기잖아요?
VCS란 임시저장소로써 내가 만드 프로그램, 문서들이 이전 버전과 어떤 차이가 있는지 알수 있게 해주는 것이죠

그럼 다시 본론으로 돌아와서 github의 정의를 다시보면
VCS역할을 수행하는 웹 사이트라 할수 있습니다.

git hub 그러면 왜 사용할까요?

1. 패키지를 올리기 위해서

사실 github를 시작하면서 가장 많이 들었던 기능이에요 다른 프로그래머들이 만든 소스코드를 다운로드 받아서
공부하고 분석해보기도 하는 정보공유의 장이랄까? 즉 개인과 개인, 팀과 팀간에 정보 공유를 위해서입니다.

2. 공동 작업을 위해

git hub에는 fork라는 기능이 있습니다. 아직 사용해 보진 않았지만 이 기능을 사용하면 user 들끼리 수정하고 받는 작업을 수월하게 해낼 수 있다고 해요. 특히 장점이라면 다른 프로그램을 깔지 않고 웹 사이트에서 볼 수 있고 코드를 쉽게 끌어 올 수 있다는 장점이 있죠

git 명령어

git init 깃 저장소 초기화
git config configure 처음에 깃 설정할 때 유용
git help 명령어를 잃어 버렸을 때 사용해보자
git status 저장소 상태 체크
             = 어떤 파일이 저장소 안에 있는지, 커밋이 필요한 변경사항이 있는지, 현재 저장소에서 어떤 작업하는지
git commit 깃의 가장 중요한 명령어 어떤 변경사항이라도 만든 후 저장소의 스냅샷을찍기위해 이용
