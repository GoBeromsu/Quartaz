파이썬 기본 문법을 거의 까먹어서 책을 한 번 쓰윽 훑어보면서 복습을 하려고 한다.

input : 원래 이렇게 썼었나???

```python
age = int(input("어서 나이를 입력하지 못할까??"))
```

위의 코드를 보면 "어서 나이를 입력하지 못할까?"라는 문장이 콘솔에 출력된다. 그 후 input 값을 정수로 받아서 age에 저장한다.

인생은 짧으니까 파이썬을 쓰라는 말이 맞는 말인 게 체감되는 코드가 아니한가?

* 함수 사용법에 관하여

```python
def sayhello(name, place = 'python world'):
    print("%s 님 안녕하세요, %s 에 오신 것을 환영합니다." %(name,place))
    return name
```

sayhello에서 place는 python world가 디폴트 세팅이다. 파이썬이 똑똑한 게, default setting이 되어 있어서 저 상황에서 인자 값이 하나만 주어지더라도 우선순위에 따라서 코드가 실행된다.

* module 제작

딱히 어려운 건 아니고, 그냥 python file을 만들어서 경로를 지정하고 import하면 된다. 그 자바랑 느낌이 비슷하던데??

`__init__` 인 게 뭔가 했더니 그냥 객체 지향을 하려고 했던 거였다. 이걸 몰라서 그리 헤맸다.

* 객체지향적 파이썬

파이썬은 객체지향적 프로그래밍을 하기 쉽다. 사실 공부하다 보니 그냥 대놓고 이렇게 만들라는 느낌이긴 했다. 캡슐 생성, 초기화, 상속이 너무 쉽다.

위에서 말했다시피 `__init__(self,object1,object2)` 이런 식으로 초기화할 인자 값들을 표시하고 생성하면 된다.

또 신기했던 게 self라는 개념인데, 그냥 말 그대로 자기 자신이다. 그런데 이게 있으니까 코드가 명시적으로 정리된다. 뭔가 간결하고 깔끔해지는 느낌이다.

## 개인사이드 프로젝트

처음에는 python으로 만들어진 툴을 C언어로 컨버팅하는 게 목적이었다.

Python tool 코드를 보니 직접 네트워킹 관련 모듈을 만든 건 아니고, scapy라는 네트워크 해킹 모듈에서 import해 기능을 세분화한 정도였다. 그래서 코드 자체가 그렇게 어렵지 않았다. 그 모듈 중에 argparse라고 기능을 세분화해주는 모듈?? 선택지를 추가해주는 모듈을 써서 껍데기를 구성한 후, 내부는 SCAPY를 쓴 거니깐.

그래서 일단 첫 번째 목표는 SCAPY MODULE을 그대로 이용하되 C언어로 만들어 볼까 한다. 모듈을 내장시킨다고 해야 하나??

데이터 값을 PYTHON에서 C로 변환하고, 이 변환된 값으로 C 루틴에서 함수 호출을 수행하고, 그 호출에서 얻은 데이터 값을 출력하면 된다.

데이터 - SCAPY(PYTHON) - C - 출력

위와 같은 구조로 일단 만들려고 한다.

일단 SCAPY에 대해 알아야 하는데 문서가 너무 커서 삽질 중이다. 그리고 모듈을 C언어로 구성된 프로그램에 내장해야 되는데 이것도 쉽지 않을 것 같아서 일단은 모듈부터 만지고 있다.
